¿Qué es CSS?

CSS (Cascading Style Sheets u hojas de estilo en cascada) es un lenguaje de diseño gráfico que se utiliza para definir la apariencia visual, el color, la tipografía, los márgenes y la maquetación de los documentos escritos en HTML o XML

Estructura y sintaxis

Una regla CSS se compone de un selector y un bloque de declaraciones: 

selector {
      propiedad: valor;
  }

Box Model

Todo elemento es una caja formada por contenido, padding, borde y margen. 

.caja {
      width: 200px;
      padding: 10px;
      border: 2px solid black;
      margin: 20px;
  }
Selectores

Eligen a qué etiquetas se les aplica el estilo: p, .clase, #id.

Especificidad

Define qué estilo gana: etiqueta, clase, id y estilo en línea.

Pseudo clases

Estilos según el estado: a:hover, li:first-child, p::before.
